# Security policy

PortKiller stops processes on your computer, so security reports matter. Thank you for taking the time.

## Reporting a vulnerability

Please report privately through GitHub: **Security › Report a vulnerability** on this repository. Do not open a public issue.

Include what you found, how to reproduce it, and the PortKiller version and OS. You will get a reply within a few days, and a fix will be released as soon as it is ready, with credit if you would like it.

## What counts

- Stopping a process that PortKiller should refuse: another user's, a system process, a recycled PID, or one whose ports changed after confirmation.
- Running commands or reading files through the interface.
- Installing an update that is not signed with the project's key.

## Supported versions

Only the latest release receives fixes. The app updates itself, so keeping it current is usually automatic.
